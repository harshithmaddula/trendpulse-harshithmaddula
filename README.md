# TrendPulse



A 4-part data pipeline that collects trending HackerNews stories, cleans them, 

analyses them with Pandas/NumPy, and visualises the results.



## Pipeline

1\. `task1\_data\_collection.py` — Fetches top stories from the HackerNews API and categorises them

2\. `task2\_data\_processing.py` — Cleans the raw data and saves it as a CSV

3\. `task3\_analysis.py` — Computes statistics and adds engagement metrics

4\. `task4\_visualization.py` — Generates charts and a summary dashboard



## How to run

\\`\\`\\`

pip install requests pandas numpy matplotlib

python task1\_data\_collection.py

python task2\_data\_processing.py

python task3\_analysis.py

python task4\_visualization.py

\\`\\`\\`



\## Output

\- `data/` — JSON and CSV files at each pipeline stage

\- `outputs/` — Generated chart PNGs
